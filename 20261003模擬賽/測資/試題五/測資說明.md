# 試題五測資說明

本目錄提供「訊息等級統計長條圖」的日誌測試資料。檔案使用 UTF-8 編碼，格式為：

```text
日期時間|等級|模組|訊息內容
```

等級包含 `DEBUG`、`INFO`、`WARNING` 與 `ERROR`。空白行不列入統計。

| 檔案 | DEBUG | INFO | WARNING | ERROR | 測試目的 |
|---|---:|---:|---:|---:|---|
| `in-1.log` | 2 | 4 | 2 | 2 | 一般統計與 ERROR 提示 |
| `in-2.log` | 0 | 0 | 0 | 0 | 空檔案與全為 0 |
| `in-3.log` | 2 | 2 | 0 | 0 | 最高值同分、沒有 ERROR |
| `in-4.log` | 0 | 0 | 0 | 4 | 只有 ERROR |
| `in-5.log` | 2 | 12 | 4 | 3 | 不同數量的比例繪製 |

繪圖條件：

- `DEBUG` 灰色、`INFO` 藍色、`WARNING` 橘色、`ERROR` 紅色。
- `ERROR > 0` 顯示「存在 ERROR 紀錄」；否則顯示「沒有 ERROR 紀錄」。
- 最大數量大於 0 時，最高分類標示 `MAX`；同分時全部標示。
- 長條高度以本次資料的最大數量作為比例基準，不要求固定的縱軸上限。
